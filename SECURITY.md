# 보안 문제 신고 / Reporting security problems

## 한국어

보안 문제(예: 앱이 허락하지 않은 파일이나 명령에 접근할 수 있는 문제, 인증 정보가 노출되는 문제)는 **공개 이슈나 Discussions에 올리지 말아 주세요.**

대신 이 저장소의 **Security › Report a vulnerability**(GitHub Private vulnerability reporting)로 알려 주세요. 신고 내용은 운영자만 볼 수 있습니다.

- 링크: https://github.com/kdonghun0510/Intentune-releases/security/advisories/new
- 함께 적어 주시면 좋은 것: 앱 버전, macOS 버전, 재현 방법, 예상되는 영향
- 실제 토큰·비밀번호·개인 정보는 넣지 말아 주세요. 예시 값이면 충분합니다.

Intentune은 개인이 운영합니다. 확인과 답변이 늦을 수 있지만, 받은 신고는 모두 확인합니다. 수정이 배포되기 전까지는 내용을 공개하지 말아 주세요.

## English

Please **do not post security problems (for example, the app reaching files or commands it was not allowed to, or credentials being exposed) as public issues or Discussions.**

Report them through this repository's **Security › Report a vulnerability** (GitHub private vulnerability reporting) instead. Only the maintainer can see the report.

- Link: https://github.com/kdonghun0510/Intentune-releases/security/advisories/new
- Helpful to include: app version, macOS version, steps to reproduce, the likely impact
- Do not include real tokens, passwords or personal data — placeholder values are enough.

Intentune is run by one person. Replies may take a while, but every report is read. Please keep the details private until a fix has been released.
